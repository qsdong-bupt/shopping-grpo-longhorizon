# 2026-11-11-03：按轨迹类别以20∶1划分SFT训练与验证

## 1. 要解决的问题

[1344条抽取记录](2026-11-11-02-curated-sft-1344.md)提供的是未划分数据池。用户要求按单候选直接完成、探索后成功、守卫纠错后成功三类，按照20∶1划分训练集和验证集。

数据还含两条重复选择或规格回切后成功轨迹，需保留并明确分配，避免划分时丢失。各类别数量无法全部被21整除，需说明整数取舍。

## 2. 希望达到的目的

- 全部1344条均进入训练或验证，训练1280条、验证64条，总比例精确20∶1。
- 按轨迹主类分层，在整数约束下尽量保持类别比例；类内可复现地随机选择。
- 训练、验证任务ID与归一化请求交叉为0。
- 所有消息、工具、审计、长度及监督标志保持原样；不启动训练或改动冻结harness。

## 3. 解决方案

将64个验证名额按各类别总数/1344分配，采用最大余数法取整，得到单候选54、探索8、守卫纠错2、重复或回切0。两条稀有规格轨迹均分到训练集。

类内用seed=20261111及类别、record_id的SHA256稳定排序确定验证样本。只对轨迹类别分层，没有附加难度、领域、Gold/JEV配额；各侧保留源文件相对顺序。权威新分组保存在assignments.json和assigned_trajectories.jsonl，后者source_split仅保留旧来源，不再用于当前分组。

在原1344条目录下新增split_20to1/，保存train.parquet、val.parquet及对应JSONL。通过Arrow按行分组，不改写消息或工具定义。split_sft1344.py作为复现附件保留，源samples.jsonl、data.parquet、抽取身份与统计指纹不变。
